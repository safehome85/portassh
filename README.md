# portassh

Портативный удалённый SSH-доступ к Windows-машинам **без прав администратора и без установки**: один exe, скопировали — запустили — подключились.

## Как работает

```
Ваш ПК ──ssh -J──► relay (любой SSH-сервер с белым IP) ◄──reverse-туннель── Windows-машина
```

На целевой машине `portassh.exe`:
1. поднимает встроенный SSH-сервер на `127.0.0.1:2222` (shell/exec/SFTP);
2. сам открывает reverse-туннель к relay-серверу по зашитому ключу.

Подключение с вашего компьютера:
```
ssh -o StrictHostKeyChecking=accept-new -J root@<relay> -p 2200 любой_логин@localhost
```

Никаких паролей, установок и прав администратора: все ключи запекаются в exe при сборке (`baked.go`), слушается только loopback (фаервол не спрашивает), конфигурации на целевой машине не требуется.

## Возможности

- **Ноль настройки на цели**: exe запускается двойным кликом, окно не появляется (статус — в `portassh.log` рядом)
- **Shell, exec и SFTP**: интерактивный cmd.exe (ConPTY), выполнение команд, `scp`/`sftp` файлы
- **UTF-8**: вывод cmd/powershell декодируется из CP866 на лету
- **Мульти-машина**: каждый экземпляр регистрируется в реестре на relay (`online.txt`), берёт свободный порт автоматически
- **Админ-режим**: `portassh.exe -admin` — окно UAC и второй экземпляр с правами администратора (свой туннель на порт 2201)
- **Живучесть**: auto-reconnect с экспоненциальным backoff, retry при блокировке запуска антивирусом (exit 127 = spawn не удался), паники изолируются и пишутся в лог
- **Один файл на всё**: 386-сборка работает на Win10/11 x64 (WOW64), x86 и ARM64 (эмуляция)

## Сборка

Требуется Go 1.21+. Скопируйте `baked.go.example` → `baked.go`, заполните своими ключами и адресом relay, затем:

```sh
./build.sh
```

Подробности генерации ключей — в комментариях `baked.go.example`.

## Настройка relay

Подойдёт любой SSH-сервер (VPS). Пользователю, под которым ходит туннель, достаточно права создавать TCP-форварды (`AllowTcpForwarding`); shell ему не нужен:

```sh
useradd -m -s /bin/sh portassh
echo "<relay_ed25519.pub>" > /home/portassh/.ssh/authorized_keys
```

## Подключение

```sh
ssh -o StrictHostKeyChecking=accept-new -J root@<relay> -p 2200 anyuser@localhost
scp -o ProxyJump=root@<relay> -P 2200 файл.ps1 anyuser@localhost:
```

## Безопасность

- exe содержит приватный ключ туннеля — **не публикуйте собранный бинарник**: держатель exe может открывать туннели через ваш relay (shell на relay при этом недоступен, если пользователю назначен ограниченный shell)
- встроенный SSH-сервер принимает подключение только с одного зашитого клиентского ключа и только через loopback
- host key relay фиксируется при сборке (TOFU не нужен)
- поведение для антивирусов: манифест `asInvoker`, никаких инсталляторов; при блокировках добавьте exe в «Доверенные приложения» Kaspersky/Defender
